Event-Condition-Action (ECA) Trigger Execution Pipeline

1. Database Event

AFTER UPDATE OF status

Fired by SQLite / MySQL engine whenever an UPDATE modifies column status in EMERGENCY.

2. Condition Check

OLD.status ≠ NEW.status

Validates that an actual status progression occurred (avoids redundant duplicate logging).

3. Pseudo-Records

OLD vs NEW In-Memory

Captures OLD.status ('Reported') and NEW.status ('Dispatched') directly from transaction buffer.

4. Trigger Action

INSERT INTO History

Persists row to EMERGENCY_STATUS_HISTORY with current timestamp and transition remarks.
