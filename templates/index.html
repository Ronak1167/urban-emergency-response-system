DBMS Transaction & Trigger Protocol (ACID Compliance)

When you click "ACID Dispatch", an atomic transaction executes via BEGIN IMMEDIATE: 1) Selects an eligible ALS / BLS Ambulance carrying functional apparatus; 2) Queries and locks a vacant ICU / General Bed at the nearest hospital; 3) Atomically updates AMBULANCE.operational_status = 'Dispatched', BED.is_occupied = 1, and records into RESOURCE_ALLOCATION; 4) Updates EMERGENCY.status = 'Dispatched' which fires the automated database trigger trg_emergency_status_update logging to EMERGENCY_STATUS_HISTORY. If any resource is missing, the entire transaction is rolled back with zero dirty writes.
